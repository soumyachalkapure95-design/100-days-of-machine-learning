# 100-days-of-machine-learning
I started exploring Machine Learning from scratch because I wanted to build a strong foundation and understand how ML actually works rather than just using libraries and copying code.
As I progressed, I learned different concepts, algorithms, mathematics, Python libraries, and worked on projects.
But somewhere in the middle, I realized something:

I was learning new things, but I was also forgetting some of the things I had already learned.
Instead of continuously moving forward and building gaps in my fundamentals, I decided to stop and brush up everything from the beginning.

That's how I started my 100 Days Machine Learning Challenge.

The goal isn't just to complete 100 days.

The goal is to understand, revise, practice, and build.
So I started relearning the concepts from CampusX by Nitish Singh
